# Awesome DESIGN.md Skill (`voltagent/awesome-design-md`)

The **Awesome DESIGN.md** standard curates and benchmarks real-world, production-proven `DESIGN.md` implementations from high-craft software companies.

---

## 1. Architectural Patterns from Benchmark Brands

- **Linear / Raycast (Precision Dark / Slate)**:
  - High-density keyboard-first UX, `1px` subtle hairline dividers (`border-white/10`), ultra-crisp monospaced shortcuts (`kbd`), saturated accent highlights.
- **Stripe / Apple (Editorial Discovery & Tactile Light)**:
  - Warm tinted paper canvases (`#f8f9fa` to `#faf9f5`), generous spatial padding, layered ambient shadows, fluid responsive typography, and tactile button physics.
- **Vercel / Supabase (Developer Precision)**:
  - Strict typographic hierarchy, zero-decoration utility grids, tabular figures on telemetry, monochromatic structure with high-contrast active states.

---

## 2. Converting Brand Guidelines into Agent Context

When building a `DESIGN.md`:
1. **Identify the Visual Atmosphere**: Define emotional tone (e.g. *Tactile Editorial Mobility*, *Instrument-Grade Fleet Management*).
2. **Standardize Hairlines & Borders**: Use `border-border/60` or `divide-border/40` rather than heavy default `border`.
3. **Contrast-Calibrated Typography**: Pair a functional Sans (`Geist`, `Inter`, `SF Pro`) with a high-character Monospace (`Geist Mono`, `JetBrains Mono`) for data, IDs, and currency.
4. **Interactive Component Tokens**: Specify explicit hover, active, focus-visible, and disabled tokens for every interactive surface.
